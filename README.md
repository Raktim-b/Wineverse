# 🌐 Wineverse – Modern Wine Store Website

Wineverse is a modern, responsive, and visually appealing wine-themed website designed to showcase premium wines, offer product details, and provide a smooth browsing experience.  
This project is built using **HTML, CSS, and JavaScript**, optimized for performance, user experience, and clean UI design.

🔗 **Live Demo:**  
**https://raktim-b.github.io/Wineverse/**

---

## 📌 Features

### 🎨 Modern & Elegant UI
- Dark, luxurious theme suitable for wine brands  
- Premium typography & matte finish styling  
- High-quality product visuals  

### 📱 Fully Responsive Design
- Looks great on mobile, tablet, and desktop  
- Adaptive layouts using responsive CSS  

### ⚡ Smooth Interactions
- Beautiful transitions and hover animations  
- Interactive product sections  
- Optimized scrolling experience with JavaScript  

### 🛍️ Product Showcase
- Dedicated product page  
- Discounts, labels, and product highlights  
- Clean bottle presentation layout  

### 🔧 Reusable Code Structure
- Organized folders: `assets/`, `style/`, `script/`  
- Modular CSS  
- JavaScript enhancements for UI behavior  

---

| Technology | Purpose |

```bash

```

Just open `index.html` in your browser.
